# קליפון

דף שבו לקוחות מעלים תמונות, סרטונים, שירים והערות לקליפ או לסרט. הכול מגיע ישר ל-Google Drive של גל, מסודר בתיקיות לפי פרקים:

```
קליפון/
  זהר_סנדר_יום_הולדת_60/
    01_ינקות/001.jpg, 002.jpg ...
    02_גן/...
    NN_השלמות/
    AI_סרטון/
    מוזיקה_והערות.txt
```

## מה יש במאגר

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | דף הלקוח. GitHub Pages מגיש אותו בכתובת `https://gzfilm.github.io/clipon/` |
| `apps-script/Code.gs` | הסקריפט שרץ בחשבון הגוגל שלך, מקבל את החומרים ושומר אותם ב-Drive |

מסך המנהל, שבו יוצרים לקוח ומקבלים קישור אישי, לא נמצא כאן. הוא נשאר פרטי אצל גל.

## התקנה חד-פעמית: הסקריפט של גוגל

1. נכנסים ל-[script.google.com](https://script.google.com) עם החשבון שאליו התמונות צריכות להגיע, ולוחצים **New project** (פרויקט חדש).
2. נותנים לפרויקט שם, למשל `קליפון`.
3. מוחקים את כל מה שכתוב בקובץ `Code.gs` ומדביקים במקומו את כל התוכן של `apps-script/Code.gs` מהמאגר.
4. שומרים (Ctrl+S או אייקון הדיסקט).
5. בוחרים למעלה את הפונקציה `setup` ולוחצים **Run** (▶). גוגל יבקש הרשאות:
   - **Review permissions**, ואז בוחרים את החשבון.
   - אם מופיע "Google hasn't verified this app": לוחצים **Advanced** ואז **Go to קליפון (unsafe)**. זה תקין, כי זה הסקריפט שלך.
   - **Allow**.

   אחרי זה תופיע ב-Drive תיקייה בשם `קליפון`.
6. **Deploy** ואז **New deployment**. ליד Select type לוחצים על גלגל השיניים ובוחרים **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - **Deploy**
7. מעתיקים את ה-**Web app URL**, הכתובת שנגמרת ב-`/exec`, ושולחים אותה לקלוד. הכתובת נכנסת לשורה `SCRIPT_URL` בתוך `index.html`.

**אם משנים את הקוד של הסקריפט אחר כך:** Deploy, ואז **Manage deployments**, עיפרון, ב-Version בוחרים **New version**, ואז Deploy. ככה הכתובת נשארת אותו דבר.

## התקנה חד-פעמית: GitHub Pages

1. במאגר ב-GitHub נכנסים ל-**Settings** ואז **Pages**.
2. ב-Source בוחרים **Deploy from a branch**, ב-Branch בוחרים `main` ו-`/ (root)`, ולוחצים **Save**.
3. אחרי דקה או שתיים הדף זמין בכתובת `https://gzfilm.github.io/clipon/`.

## קישור אישי ללקוח

כל לקוח מקבל קישור כמו `https://gzfilm.github.io/clipon/?c=...`. החלק שאחרי `?c=` מקודד את שם הלקוח, סוג הקליפ והפרקים. את הקישור מייצרים במסך המנהל, בכפתור "העתק הודעה לווטסאפ".

בלי `?c=` הדף נפתח כלקוח כללי לבדיקה, והחומרים נשמרים בתיקייה שמתחילה ב-`בדיקה_`.

## הגדרות שאפשר לשנות

בתחילת הסקריפט ב-`index.html`:

- `IMG_MAX` ו-`IMG_Q`: כיווץ התמונות. כרגע הצלע הארוכה עד 3000 פיקסל, באיכות JPEG של 88%. כדי לשלוח תמונות מקוריות בלי כיווץ, משנים ל-`IMG_MAX=0`.
- סרטונים תמיד נשלחים במקור.

ב-`apps-script/Code.gs`:

- `NOTIFY_BY_EMAIL`: מייל אליך בכל פעם שלקוח שולח. כדי לכבות, משנים ל-`false`.

## איך זה עובד מאחורי הקלעים

- כשלוחצים "שלחו לגל", הדף יוצר את תיקיית הלקוח ואת כל תיקיות הפרקים, ושולח שלושה קבצים במקביל. במהלך השליחה מוצג פס התקדמות.
- סרטון גדול נשלח בחתיכות של 8MB. אם החיבור נופל באמצע, הדף ממשיך מאותה נקודה.
- כל קובץ מקבל מספר לפי הסדר שהלקוח קבע (`001`, `002`...). במשלוח נוסף המספור ממשיך מהמספר האחרון שכבר נמצא בתיקייה.
- הכותרת, השירים, ההערות לכל קובץ והתיקונים נכתבים בסוף `מוזיקה_והערות.txt`, עם תאריך לכל משלוח. שום דבר לא נמחק.
- הסקריפט כותב רק בתוך התיקייה `קליפון` ב-Drive, ולא יכול לגעת בשום מקום אחר.
